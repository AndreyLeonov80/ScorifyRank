# Frontend src

Эта папка — подготовительный слой для постепенного перехода от больших HTML + `js/script.api.js`
к небольшим React/Preact-модулям.

Текущие HTML-страницы пока не переключены на `src`, чтобы не сломать рабочий интерфейс.
Новые модули можно подключать по одному экрану после smoke-проверки.

## Первый слой

- `api/client.js` — единый клиент backend API с fallback на новый backend `8009` и legacy `8001`.
- `api/endpoints.js` — именованные endpoint-функции без UI-логики.
- `shared/format.js` — общие форматтеры для чисел и размеров.
